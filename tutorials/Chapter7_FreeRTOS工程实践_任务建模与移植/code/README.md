# Chapter7 code

本目录用于后续 FreeRTOS 工程实践示例。Chapter7 的代码重点不是复刻内核，而是展示真实 STM32 工程里如何组织任务、通信和移植层。

| 目录 | 目标 |
|------|------|
| `stm32_freertos_minimal/` | 最小多任务 STM32 FreeRTOS 工程骨架 |
| `cubemx_cmsis_compare/` | CubeMX/CMSIS-RTOS 与直接 FreeRTOS API 对照 |
| `dma_irq_notify_demo/` | DMA + IRQ + task notification 通信链路 |
| `task_analysis_example/` | 任务表、甘特图和可调度性分析示例 |
