4.3寸    分辨率：800*480

屏幕芯片：ILI9806G（现生产使用）NT35510（停产）

4.5寸（停产）   分辨率：854*480

屏幕芯片：ILI9806G 

电容触摸芯片： GT5688  


1.不同尺寸型号的屏幕驱动在程序中的差异具体请看开发板库教程中“LCD-液晶显示” 章节的 “补充说明” 部分。
因为旧的4.5寸屏幕的芯片与现4.3寸同使用ILI9806G芯片驱动，但是在4.3寸屏中错误下载4.5寸的相关例程会使屏幕出现白条，并且下载回正确的4.3寸例程任然残留白条，
这是正常现象，不是屏幕问题，屏幕运行一段时间白条便会自然慢慢消失，另外请尽量不要下载错例程。



2.因为厂商芯片生产供应等问题，请用户以实际所使用的屏幕尺寸和触摸芯片型号为准。

关于有使用到触摸部分的程序：
触摸芯片本身出厂时已经保存好适合的参数，同型号的不同批次芯片参数可能有差异，
现在对于会使用到触摸的基础画板，emwin，开机演示等例程都改为了默认不要重复写入参数，
同时因为触摸芯片型号替换，例程里面会随现生产的屏幕添加多种触摸芯片型号的ID标识，

以上的描述在程序里面的更新会与些视频文档教程等有差异，请用户具体阅读源码了解，例程整体流程逻辑没有变化。


在gt9xx.h或者gt5xx.h中  （例程touch文件夹内容的C和H文件在例程中保留为原来名字）

添加了一个控制是否更新配置的宏

#define UPDATE_CONFIG    0    // 1 ：更新配置    0 ：不更新配置

对应于gt9xx.c或者gt5xx.c中

int32_t GTP_Init_Panel(void) 函数

	……

	I2C_Touch_Init();

	//获取触摸IC的型号
	GTP_Read_Version(); 

	#if UPDATE_CONFIG

	……（写入操作）

	#endif

	……


上面条件编译内含的部分既是根据先读取触摸芯片的型号来分别使用不同的配置数组和流程对触摸芯片重新写入参数，
配置数组在gt9xx.c或者gt5xx.c中定义，同一个型号的芯片可能有不同批次对应的数组，通过注释选择，数组值由厂商提供，
默认不需要重复写入，程序其他流程没有改动，如果因为使用了旧例程、尝试写入但写入后变异常不能恢复等情况请联系野火询问，
先确认当前所使用屏幕的触摸芯片型号在对应开发板的最新触摸画板例程下能否正常使用。
